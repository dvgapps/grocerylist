Common questions

How do I back up my list?

Open Settings → Database Management → Back up now and choose where to save the file. To use it on another phone, copy the file there and choose Restore from backup. You can also use Show my last backup location to find it.

Where is my data stored?

On your phone only. See the privacy policy for the optional features that contact outside services.

A barcode scan did not find my product.

Product details come from the free Open Food Facts database, which does not have every product. You can still add the item by typing its name and price.

I want to start over.

Use Settings → Database Management → Reset all data to stock. You will see an Undo button for a few seconds afterwards. Making a backup first is the safest choice.

Does the app need an account?

No. There is no sign-in and no cloud service.
